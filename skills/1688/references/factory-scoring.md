# 1688 工厂综合评分与排序指南

本文件定义如何从多个维度给 1688 工厂打分，并给出最终排序优先级。评分目标：**信息真实、产能可靠、物流便宜、匹配度高、风险低**。

---

## 一、评分维度总览

| 维度 | 权重（默认） | 数据来源 | 核心指标 |
|------|------------|---------|---------|
| 信息完整度 | 18.5% | 1688 contactinfo / 店铺页 | 电话、手机、地址、联系人、邮箱、网址 |
| 企业官网 | 1.5% | 1688 店铺页 / 搜索引擎 / 天眼查 | 是否有独立官网、官网可访问性、内容丰富度 |
| 域名注册时间 | 1% | WHOIS / 域名注册信息 | 域名注册年限 |
| 工商可信度 | 15% | 天眼查（Kimi）/ Bing / Google | 存续状态、注册资本、法人、参保人数 |
| 公司规模与实力 | 15% | 天眼查 / 1688 店铺页 | 参保人数、注册资本、厂房面积、年营业额 |
| 主营产品 | - | 1688 factory 页 / 旺铺页 | 用于产品匹配评分和供应商数据库归档 |
| 工厂成立时长 | 10% | 天眼查 | 企业工商注册成立时间 |
| 1688 店铺开店时长 | 5% | 1688 店铺页 | 在 1688 平台的开店年限 |
| 产品匹配度 | 15% | 1688 factory 页 / 搜索结果 | 标题/类目/产品描述与关键词匹配程度 |
| 物流距离 | 15% | `references/logistics-*.md` | 到最近空/海/陆口岸的距离 |
| 1688 活跃度 | 5% | 1688 店铺页 | 店铺等级、响应率、近 90 天成交、回头率 |

| 资质认证 | 1% | 1688 店铺页 / 天眼查 | ISO、CE、FDA、SGS 等证书 |
| 风险扣分项 | - | 天眼查 / 公开信息 | 经营异常、司法诉讼、行政处罚、失信记录 |

**默认总分 = 各维度加权得分 - 风险扣分**

总分范围：0-10，保留 1 位小数。

## 二、各维度评分细则

### 1. 信息完整度（18.5%）

从 1688 `contactinfo.htm` 或 factory 黄页提取：

| 字段 | 分值 |
|------|------|
| 电话（座机） | 3 |
| 手机 | 3 |
| 详细地址（到市/县） | 3 |
| 联系人姓名 | 3 |
| 邮箱 / 网址 / 微信 / QQ | 每个 2，上限 8 |

满分 20 → 映射到 10 分后再 × 0.185。

### 2. 企业官网（1.5%）

从 1688 店铺页、contactinfo 或天眼查获取官网 URL，访问并评估：

| 指标 | 评分 |
|------|------|
| 有独立企业官网，可正常访问，内容完整（公司简介、产品、联系方式、工厂图片/视频） | 10 |
| 有独立官网，可访问，但内容较简单 | 6 |
| 有独立官网，但无法访问或加载异常 | 3 |
| 无独立官网，仅有 1688 店铺页 | 0 |

**官网访问后可额外判断（不直接计分，用于排序参考）：**
- 官网展示工厂实景、生产线、设备照片/视频 → 可信度高
- 官网有 ISO/CE 等认证展示 → 与资质认证维度互证
- 官网联系方式与 1688 一致 → 工商可信度加分参考
- 官网域名备案主体与公司名称一致 → 工商可信度加分参考

### 3. 域名注册时间（1%）

通过 WHOIS 查询或域名注册信息获取官网域名注册时间：

| 注册时间 | 评分 |
|---------|------|
| ≥ 10 年 | 10 |
| 5-10 年 | 8 |
| 3-5 年 | 6 |
| 1-3 年 | 3 |
| < 1 年 | 1 |
| 无官网或无法查询 | 0 |

域名注册时间越长，说明企业线上品牌沉淀越久，稳定性越高。

### 4. 工商可信度（15%）

通过天眼查（Kimi）或搜索引擎补充：

| 指标 | 评分 |
|------|------|
| 企业状态为“存续/在业” | 4 |
| 有统一社会信用代码 | 2 |
| 注册资本 ≥ 100 万 | 3 |
| 注册资本 10-100 万 | 1 |
| 天眼查数据与 1688 信息一致（公司名、地址、法人） | 3 |
| Google/Bing 交叉验证通过（电话/地址/官网一致） | 2 |

**Google/Bing 交叉验证方法：**
- 搜索 `"公司名称"` + `"电话"` / `"地址"` / `"官网"`
- 比对搜索结果与 1688 提取信息是否一致
- 在第三方 B2B 平台（阿里巴巴国际站、Made-in-China、环球资源）找到同名企业且信息一致 → 可信度更高
- 发现多个矛盾信息 → 工商可信度扣分参考

## 三、综合得分计算公式

```
信息完整度得分   = 信息完整度原始分 / 20 * 10 * 0.185
企业官网得分     = 官网原始分 * 0.015
域名注册时长得分 = 域名注册原始分 * 0.01
工商可信度得分   = 工商可信度原始分 / 15 * 10 * 0.15
规模实力得分     = min(规模原始分 / 13 * 10, 10) * 0.15
工厂成立时长得分 = 成立时长原始分 * 0.10
1688店龄得分     = 店龄原始分 * 0.05
产品匹配度得分   = 匹配度原始分 * 0.15
物流距离得分     = 物流原始分 * 0.15
1688 活跃度得分  = 活跃度原始分 / 10 * 10 * 0.05
合作伙伴得分     = 合作原始分 / 3 * 10 * 0.03
资质认证得分     = 认证原始分（最高 1 分） * 0.01

基础总分 = 以上各项之和
最终总分 = 基础总分 - 风险扣分
最终总分 = max(0, min(10, 最终总分))
```

## 四、排序与优先级

### 默认排序

按 **最终总分降序**。总分相同：
1. 产品匹配度高的优先
2. 物流距离分高的优先
3. 信息完整度高的优先
4. 工厂成立时间长的优先
5. 1688 店铺开店时间长的优先
6. 域名注册时间长的优先

### 优先级分级

| 总分 | 优先级 | 建议 |
|------|--------|------|
| 8.0 - 10 | 高 | 优先联系、重点考察 |
| 5.0 - 7.9 | 中 | 备选，可作为比价对象 |
| 2.0 - 4.9 | 低 | 信息不足或风险较高，谨慎考虑 |
| 0 - 1.9 | 排除 | 不建议联系 |

### 用户指定偏好时

如果用户明确强调某一点，临时调整权重：

| 用户偏好 | 权重调整建议 |
|---------|------------|
| 要便宜运费 | 物流距离 +10%，产品匹配度 -5% |
| 要大厂/有保障 | 公司规模 +10%，工商可信度 +5% |
| 要快速响应 | 1688 活跃度 +5%，信息完整度 +5% |
| 要精准匹配 | 产品匹配度 +10% |
| 要老牌工厂 | 工厂成立时长 +10% |
| 要有背书 | 合作伙伴 +3%，资质认证 +2% |
| 要注重官网/品牌 | 企业官网 +1%，域名注册时间 +1% |

## 七、注意事项

1. **不要追求 100% 数据完整**。某些工厂未公开参保人数、官网或域名信息，按 0 分处理即可。
2. **天眼查数据以 Kimi 为主**。非 Kimi 环境用搜索引擎补充，可信度和完整性会下降。
3. **风险扣分优先**。一旦有经营异常、失信、吊销，应显著降权或排除。
4. **产品匹配度是硬性门槛**。匹配度低于 4 分的工厂即使其他维度好，也不应进入前三推荐。
5. **工厂成立时长 ≠ 1688 店龄 ≠ 域名注册时间**。三者分别反映企业稳定性、平台运营经验和线上品牌沉淀。
6. **交叉验证是重要风控手段**。通过 Google/Bing 搜索发现信息矛盾时，即使其他维度得分高，也应降权。
7. **主营产品必须持久化**。每次提取到的 `mainProducts` 要保存到供应商数据库，作为后续检索、分类、二次筛选的基础字段。
8. **用户偏好优先**。最终排序前询问用户更看重哪一点，再调整权重。
