# 1688 供应商物流参考：海运口岸（港口海关）

本表列出中国大陆主要具备海运进出口报关能力的港口口岸，用于估算工厂到海运出口通道的距离。

**使用场景：** 当目标市场以海运为主（大宗、低货值、大体积、不赶时效），或订单以 FCL/LCL 出口时，优先选择距离海港近的工厂，可显著降低拖柜/集卡成本。

## 距离估算规则

1. **从工厂地址提取省份/城市**（`address` 字段）。
2. **沿海/沿江省份**优先匹配同省或邻近港口。
3. **内陆省份**通常需先陆运/铁路到沿海港口，距离越远国内段成本越高。
4. 使用经纬度差值快速估算（1° 纬度 ≈ 111 km；1° 经度 ≈ 111 km × cos(纬度)）。

## 优先级建议

| 工厂位置与最近港口关系 | 物流优先级分 |
|----------------------|------------|
| 同城市或 100 km 内 | 10 |
| 同省/直辖市 100-300 km | 7-8 |
| 邻近省份 300-600 km | 4-6 |
| 内陆省份 600-1000 km | 2-3 |
| 偏远地区 >1000 km | 1 |
| 地址无法解析 | 0 |
