# 1688 供应商物流评分：距离海关/口岸维度

本文件定义如何根据工厂地址到最近海关/运输口岸的距离，给工厂打分并排序。

**核心目标：** 距离越近，国内段运输成本越低、时效越快，优先级越高。

## 适用场景

- 海运出口：参考 `logistics-seaports.md`
- 空运出口：参考 `logistics-airports.md`
- 陆运出口（中亚/俄罗斯/东南亚/欧洲）：参考 `logistics-land-ports.md`

用户未指定运输方式时，**默认使用海运**（1688 批发最常见）。

## 评分维度

| 维度 | 权重（建议） | 说明 |
|------|------------|------|
| 最近口岸距离 | 100%（本维度） | 综合空/海/陆三种方式中的最近得分 |
| 目标市场方向 | 可选 | 若用户指定了目标市场，优先匹配对应方向的口岸 |

## 评分步骤

### Step 1: 解析工厂地址

从 `address` 字段提取：
- 省份/直辖市/自治区（如“浙江”、“广东”、“新疆”）
- 城市/地级市（如“宁波”、“深圳”、“喀什”）

### Step 2: 选择运输方式

| 用户输入 | 选用参考表 |
|---------|-----------|
| 海运 / FCL / LCL / 大批量 | `logistics-seaports.md` |
| 空运 / 快递 / 高货值 / 急单 | `logistics-airports.md` |
| 陆运 / 中亚 / 俄罗斯 / 东南亚陆路 / 中欧班列 | `logistics-land-ports.md` |
| 未指定 | 同时计算三种，取最高分 |

### Step 3: 计算最近口岸距离分

对选定的口岸列表，计算工厂地址到每个口岸的近似距离：

```
dLat = abs(工厂纬度 - 口岸纬度)
dLon = abs(工厂经度 - 口岸经度)
distance_km ≈ sqrt((dLat * 111)^2 + (dLon * 111 * cos(工厂纬度 * π/180))^2)
```

取最小距离，映射为 0-10 分：

| 最近距离 | 得分 |
|---------|------|
| ≤ 100 km | 10 |
| 100-300 km | 8 |
| 300-500 km | 6 |
| 500-800 km | 4 |
| 800-1200 km | 2 |
| > 1200 km | 1 |
| 地址无法解析 | 0 |

### Step 4: 综合物流优先级

若用户指定了目标市场，按方向对口岸加权：

| 目标市场 | 优先口岸方向 |
|---------|-------------|
| 欧美/中东/非洲 | 海运港口 > 空运机场 |
| 中亚/俄罗斯 | 陆运口岸（阿拉山口、霍尔果斯、二连浩特、满洲里） |
| 东南亚 | 海运港口（深圳、广州、宁波、上海）或陆运口岸（凭祥、东兴、磨憨） |
| 日韩 | 海运港口（青岛、天津、大连、上海、宁波）或空运机场 |
| 南亚（巴基斯坦/尼泊尔） | 陆运口岸（红其拉甫、吉隆） |

加权方式：目标市场匹配方向的口岸得分 × 1.2，最高不超过 10。

### Step 5: 融入工厂总评分

建议总评分结构：

| 维度 | 权重 | 来源 |
|------|------|------|
| 信息完整度 | 30% | 电话/手机/地址/联系人是否齐全 |
| 工商信息可信度 | 20% | 天眼查/搜索引擎验证结果 |
| 物流距离 | 25% | 本文件计算的口岸距离分 |
| 响应/活跃度 | 15% | 1688 店铺等级、响应率、年限 |
| 产能/规模 | 10% | 员工数、厂房面积、年营业额（如有） |

物流距离分越高，总评分越高，排序越靠前。

## 输出示例

```markdown
| 公司 | 省份 | 最近口岸 | 运输方式 | 距离分 | 总评分 |
|------|------|---------|---------|--------|--------|
| 示例轴承有限公司 | 浙江 | 宁波舟山港 | 海运 | 9 | 8.5 |
| 示例五金厂 | 四川 | 成都天府机场 | 空运 | 6 | 6.8 |
| 示例纺织厂 | 新疆 | 阿拉山口 | 陆运 | 8 | 7.2 |
```

## 简化规则（无经纬度时）

如果无法获取工厂经纬度，使用省份匹配快速估算：

| 工厂省份与口岸关系 | 估算得分 |
|------------------|---------|
| 同省/直辖市且口岸所在城市与工厂同城市 | 9-10 |
| 同省/直辖市不同城市 | 6-8 |
| 邻近省份 | 4-5 |
| 相隔 1-2 省 | 2-3 |
| 偏远/相隔多省 | 1 |
| 无法判断 | 0 |
