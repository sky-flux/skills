# 1688 供应商物流参考：陆运口岸（边境/跨境关口）

本表列出中国大陆主要具备公路/铁路跨境运输能力的陆路口岸，用于估算工厂到陆运出口通道（尤其面向中亚、俄罗斯、东南亚、欧洲）的距离。

**使用场景：** 当目标市场为俄罗斯、中亚五国、蒙古、东南亚陆路国家，或采用中欧班列/中亚班列/中老铁路时，优先选择距离陆路口岸近的工厂，可降低国内段汽运/铁路短驳成本。

## 距离估算规则

1. **从工厂地址提取省份/城市**（`address` 字段）。
2. **同一省份/邻近省份**：优先匹配同方向口岸。
3. **跨省估算**：使用经纬度差值快速估算（1° 纬度 ≈ 111 km；1° 经度 ≈ 111 km × cos(纬度)）。
4. 需结合目标市场方向：面向俄罗斯选中俄口岸，面向中亚选中亚口岸，面向东南亚选西南口岸。

## 优先级建议

| 工厂位置与最近口岸关系 | 物流优先级分 |
|----------------------|------------|
| 同城市或 150 km 内 | 10 |
| 同省/邻近省份 150-400 km | 7-8 |
| 邻近省份 400-800 km | 4-6 |
| 较远省份 800-1500 km | 2-3 |
| 偏远地区 >1500 km | 1 |
| 地址无法解析 | 0 |
